# 03 - 分句配音工作台 Web 界面集成 (Sentence Studio WebUI)

**What to build:**
在 `omnivoice/cli/demo.py` 中以独立 Tab 形式集成“分句配音工作室 (Sentence Studio)”：
1. **控制面板区**：
   - 参考音频上传组件（支持一键 Whisper 识别参考文本）与语言/语速/推理设置；
   - 大文本输入框（支持用户一次性粘贴脏格式长文本）；
   - 主操作按钮：【分开输出 / 批量生成】。
2. **分层结果展示与交互卡片**：
   - 生成后动态逐行渲染分句卡片：
     - 序号标签（如 `01`、`02`）；
     - 可编辑文本框（展示清洗后的该句文本，允许用户直接二次修改）；
     - 独立音频播放器（即时试听本句生成的发音）；
     - 单句【重新生成】操作按钮（点击仅重跑本行）。
3. **全局导出区**：
   - 顶部/底部常驻【一键打包下载全部 (ZIP)】按钮；
   - 点击即时生成并下载 `01_xxx.wav`、`02_xxx.wav` 压缩包。
4. **零破坏与高内聚保障**：
   - 原有“声音克隆”、“音色设计”、“角色库”三个 Tab 逻辑与代码保持 100% 独立运行，不产生任何副作用。

**Blocked by:** 02 - 分句配音调度引擎与单句重试器

**Status:** complete

**Use check:**
启动 WebUI，在浏览器打开分句配音工作台：
1. 上传一段参考音频；
2. 粘贴一段带有空行与换行的 5 句话文本，点击【分开输出】；
3. 界面逐行显示 5 个带编号的播放器；
4. 修改第 2 句文本并点击该行的【重新生成】，第 2 句播放器更新为新音频；
5. 点击【全部打包下载】，成功下载包含 5 个按序编号 `.wav` 文件的 ZIP 包。

- [x] 支持大文本一键拆分与批量按序生成
- [x] 逐行显示序号、文本框、播放器与独立重试按钮
- [x] 单句重跑后局部刷新该句音频
- [x] 一键导出全部有序 WAV 文件的 ZIP 压缩包
