# User Profile & Collaboration Preferences

## 用户偏好与交互风格
- **首选交互语言**：中文（简体）。
- **运行平台**：Windows 操作系统，配备本地 GPU 或开发环境。
- **操作风格**：
  - 关注工程落地与完整性，重视系统化治理与规范（如 `pe-0` 与 `repo-项目即角色` 契约）。
  - 不喜欢残缺的脚手架、仅有提案无实装或遗留无主临时文件的行为。
  - 重视磁盘整洁与空间管控，禁止将大文件随意抛入系统盘。
  - 希望在启动与测试时能便捷调用批处理脚本（如 `start_demo.bat`）或直接利用 CLI 进行验证。
