# DAT-001: 音频降噪与质量预处理

## 用途与可观察行为
处理野外或网络爬取的大规模语音数据中伴随的背景底噪、杂音与混响。提供离线自动化降噪工具，显著提升后续神经声学标记提取的纯净度与模型声学保真上限。

## 触发方式与参数
```bash
python -m omnivoice.scripts.denoise_audio \
    --input_dir /path/to/raw_audio \
    --output_dir /path/to/clean_audio \
    --batch_size 16
```

## 主流程
1. 遍历待处理音频目录，按批次加载音频波形。
2. 调用降噪处理模型（如 DFN / DeepFilterNet 等专业语音增强算法）分离人声与环境底噪。
3. 统一重采样并归一化输出至目标采样率（24kHz）。
