# DAT-002: 神经离散音频标记提取

## 用途与可观察行为
将清洗后的时域连续语音信号转换为离散的 8 层残差向量量化（RVQ）整数 Token 矩阵（Shape: `(8, T)`）。支持在多卡环境下利用 HiggsAudioV2 分词器进行极速并行离线提取，并支持在提取过程中注入环境底噪/高斯白噪作为数据增强，以提升下游模型抗噪鲁棒性。

## 触发方式与示例
```bash
# 1. 常规离散标记提取
python -m omnivoice.scripts.extract_audio_tokens \
    --input_jsonl data/train_raw.jsonl \
    --output_jsonl data/train_with_tokens.jsonl \
    --tokenizer_path eustlb/higgs-audio-v2-tokenizer \
    --batch_size 32

# 2. 注入噪声的数据增强提取
python -m omnivoice.scripts.extract_audio_tokens_add_noise \
    --input_jsonl data/train_raw.jsonl \
    --output_jsonl data/train_noisy_tokens.jsonl \
    --noise_dir /path/to/noise_samples
```

## 数据流向与数据结构
- 输出每条样本结构包含：
  - `id`: 音频唯一标识
  - `text`: 规范化转写文本
  - `audio_tokens`: shape 为 `(8, num_frames)` 的整数数组，词表大小为 1025（含 Mask ID 1024）。
