# 04-数据准备与处理管线

## 边界与职责
本功能块覆盖大规模语音数据集的清洗、降噪、离散 Token 提取离线预处理，以及面向高效训练的 WebDataset 分片存储与基于动态 Token 数量的批处理组装。

- **代码前缀**：`DAT`
- **主要受众**：数据算法工程师、模型训练工程师

- [DAT-002-神经离散音频标记提取.md](DAT-002-神经离散音频标记提取.md)：多卡并行提取 8 层残差量化声学 Token 并支持加噪增强。
