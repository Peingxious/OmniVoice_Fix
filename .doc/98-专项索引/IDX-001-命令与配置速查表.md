## 2. Python API 核心参数速查 (`generate`)

```python
audio = model.generate(
    text="合成文本内容",                     # 必填：目标文本
    ref_audio="ref.wav",                     # 可选：声音克隆参考音频路径
    ref_text="参考转写文本",                 # 可选：参考音频文本（省略自动 ASR）
    voice_clone_prompt=prompt,               # 可选：直接载入持久化的 VoiceClonePrompt
    instruct="female, low pitch, 四川话",     # 可选：音色设计属性指令
    num_step=32,                             # 扩散迭代步数（16~32）
    guidance_scale=2.0,                      # CFG 引导系数
    speed=1.0,                               # 语速调节
    duration=None,                           # 固定输出音频时长（秒，覆盖 speed）
    normalize_text=False                     # 是否规整数字/日期（需安装 [tn]）
)
```
