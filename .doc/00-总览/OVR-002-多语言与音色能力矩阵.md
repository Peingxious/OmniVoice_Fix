# OVR-002: 多语言与音色能力矩阵

## 用途与可观察行为
OmniVoice 提供迄今支持语种最广泛的零样本 TTS 能力之一，支持超过 600 种人类语言与方言。同时支持三种核心生成范式：
1. **零样本声音克隆 (Voice Cloning)**：仅需 3~10 秒参考音频即可精确迁移音色。
2. **自然语言音色设计 (Voice Design)**：通过属性指令（性别、年龄、音调、口音、方言、耳语）创造全新虚拟音色。
3. **随机/自动音色 (Auto Voice)**：模型基于文本情感与上下文自适应决定音色表现。

此外支持内联副语言符号插入与针对多语种的精准发音纠正。

## 语言与能力矩阵
| 模式 | 语言覆盖度 | 依赖要素 | 典型应用场景 |
| :--- | :--- | :--- | :--- |
| **Voice Cloning** | 600+ 语种（详见 `docs/languages.md` 与 `lang_id_name_map.tsv`） | `ref_audio` (+ 可选 `ref_text`) | 有声书配音、角色声线复刻、跨语种多语言翻译配音 |
| **Voice Design** | 专注中英文（泛化支持其它语种） | `instruct` 文本属性组合 | 虚拟助手性格塑造、短视频解说定制、NPC 角色声音定制 |
| **Auto Voice** | 全语种支持 | 仅需 `text` | 快速内容朗读、盲测与通用文本语音转换 |
| **副语言控制** | 中英文为主 | 内联非言语标签如 `[laughter]`, `[sigh]` | 戏剧化对白、情感充沛的口语交互 |
| **发音纠偏** | 中文/英文 | 中文拼音带声调（如 `ZHE2`）、英文 CMU 音标 | 多音字校准、专业生僻术语、缩写与品牌发音纠正 |
