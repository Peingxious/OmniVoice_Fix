# TRN-001: 扩散语言模型预训练与训练器

## 用途与可观察行为
实现 OmniVoice 的核心扩散学习算法。在前向传播中对声学 Token 施加时间步掩码或随机加噪，训练 Transformer 骨干网络恢复原始离散 Token；设计了多码本分层加权损失函数（前层码本权重高、细化层码本权重适度衰减），指导模型稳定收敛。

## 触发方式与配置
- 运行训练：
  ```bash
  python -m omnivoice.cli.train \
      --train_config examples/config/train_config_emilia.json \
      --data_config examples/config/data_config_emilia.json
  ```
- 训练配置文件关键项：
  - `audio_codebook_weights`: 默认 `[8, 8, 6, 6, 4, 4, 2, 2]`，体现不同残差量化层级的重要性权衡。
  - `attn_implementation`: `"flex_attention"` 或 `"sdpa"`。
  - `lr`, `warmup_steps`, `max_steps` 等标准优化器参数。

## 核心实现
1. **损失计算 (`OmniVoice.forward`)**：
   - 提取各码本 logits，计算 Cross-Entropy Loss。
   - 按 `normalized_audio_codebook_weights` 加权求和，输出标量 Loss。
2. **Trainer 引擎**：
   - [omnivoice/training/trainer.py](file:///d:/BaiduNetdiskWorkspace/OmniVoice/omnivoice/training/trainer.py) 负责梯度累积、混合精度缩放、学习率调度（Cosine Decay）、日志记录与评估触发。
