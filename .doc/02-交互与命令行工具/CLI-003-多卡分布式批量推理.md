# CLI-003: 多卡分布式批量推理 (`omnivoice-infer-batch`)

## 用途与可观察行为
面向大规模有声书制作、离线语音合成评测集生成与工业化高吞吐场景。能够自动发现多张可用 GPU，将结构化 JSONL 测试集均匀分发至各 GPU 进程执行批量推理，自动计算实时时延与实时率（RTF, Real-Time Factor），并将所有生成音频与度量元数据结构化归档。

## 触发方式与参数
```bash
omnivoice-infer-batch \
    --model k2-fsa/OmniVoice \
    --test_list test.jsonl \
    --res_dir results/ \
    --batch_size 8 \
    --num_step 32 \
    --enable_flashinfer true
```

## 测试清单 JSONL 数据契约
每行一个独立的 JSON 记录，支持字段如下：
```json
{
  "id": "sample_001",
  "text": "Hello world, this is a batch inference test.",
  "ref_audio": "/path/to/ref.wav",
  "ref_text": "Reference transcript",
  "instruct": "female, british accent",
  "language_id": "en",
  "duration": 10.0,
  "speed": 1.0
}
```
- `id` 与 `text` 为必填项。
- `ref_audio` 存在时走音色克隆；`instruct` 存在时走音色设计；均无时走自动音色。
- `language_id`, `duration`, `speed` 均为可选覆盖参数。

## 吞吐与加速支持
- 支持 `--enable_flashinfer true` 激活 FlashInfer 序列打包与算子融合，吞吐最高提升 2.6x。
- 自动按进程切分数据分片，每个 rank 处理对应子集，最后汇聚生成统计报告。
