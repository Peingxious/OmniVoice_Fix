# CLI-001: 交互式网页演示服务 (Gradio WebUI)

## 用途与可观察行为
基于 Gradio 构建的现代化、深色玻璃拟态交互式 Web 界面。提供清晰高效的四页面全能闭环架构：
1. **页面一：声音克隆 (Voice Clone)**：主力声音复刻与角色入库通道。支持上传参考音频、一键 Whisper 智能转写、输入目标文本、抑扬顿挫控制与即时生成试听；折叠面板中支持**自定义角色命名保存**（保存为 `voices/<角色名>.pt`，防覆写安全保护），保存后瞬间跨页联动刷新角色调用库并自动选中。
2. **页面二：分句配音工作室 (Sentence Studio)**：长篇台词配音与分段制作工作台。支持一次性粘贴长文，按行智能清洗切分（一行一句，空行自动剥离，连句逗号不拆），全篇复用同一参考音色保证前后高度一致；逐行分层呈现序号、文本、播放器与“重跑本句”按钮，支持单句微调重算与一键全部打包下载（ZIP 导出排好序的 `01_xxx.wav`, `02_xxx.wav`）。
3. **页面三：角色调用生成 (Direct PT Inference)**：直接调用已保存好的 `.pt` 角色（或拖拽上传外部 `.pt` 文件），输入待合成长短文本直接生成语音，完全免除重复上传音频与重复 ASR，实现秒级高保真合成；内置长音频响应式自适应全景波形与暗色防遮挡时间栏。
4. **页面四：声音设计 (Voice Design)**：通过性别、年龄、音调、口音与汉语方言等属性自由组合定制专属虚拟音色。

全站支持 600+ 语言下拉选择、麦克风实时拾音、中英文双语即时切换（状态自动存盘至 `settings.json`）。

## 触发方式
- 批处理脚本一键启动：运行 `start_demo.bat`（自动侦测 Tailscale 状态并输出双端访问地址）
- 命令行直接启动：
  ```bash
  # 本机私有访问
  omnivoice-demo --ip 127.0.0.1 --port 8001
  # 局域网与 Tailscale 远程访问
  omnivoice-demo --ip 0.0.0.0 --port 8001
  ```
- 访问地址：
  - 本机访问：`http://127.0.0.1:8001`
  - Tailscale 跨设备访问：`http://<Tailscale-IP>:8001`（如 `http://100.91.115.73:8001` 或 `http://px001:8001`）

## 页面架构与输入输出

### 1. 声音克隆 (Voice Clone)
- **输入**：
  - 参考音频（上传/录音，推荐 5~15 秒黄金纯净干声）。
  - 参考文本（支持点击“🎙️ 自动识别参考音频台词”一键 Whisper ASR 转录，亦可手工微调）。
  - 待合成目标文本（纯净输入框，直接键入文本，支持自然标点与非语言标签）。
  - 语种选择：支持药丸极速直切 `[🌐 自动检测]`、`[🇨🇳 中文]`、`[🇬🇧 英文]`。
  - 抑扬顿挫起伏度：独立滑块（0.0~0.8）与 4 种快捷预设。
  - 角色命名保存：展开保存面板输入角色名称（如“杨总”），一键保存为 `voices/<角色名>.pt`。
- **输出**：
  - 即时试听与下载 24kHz WAV 高清音频。
  - 保存 `.pt` 角色文件，自动同步刷新页面二的角色下拉列表与声纹详情卡片。

### 2. 分句配音工作室 (Sentence Studio)
- **输入**：
  - 音色来源支持双模式切换：
    - **模式一（直接调用已存角色）**：从 `voices/` 角色库直接下拉选择已有的 `.pt` 角色（支持一键刷新、查看声纹信息卡片），完全免去重复上传音频；
    - **模式二（临时上传新参考音频）**：上传参考音频文件或麦克风录制，支持一键 Whisper ASR 提取台词；
  - 长篇台词大文本（多行文本，支持空行、换行格式，自动按行清洗拆分）；
  - 目标发音语言、语速微调与语气控制。
- **输出**：
  - 分层逐行呈现：序号（如 `01`）、可编辑单句文本框、独立播放器、单句重跑按钮。
  - 单句重跑：现场修改某句文本或直接点击【重跑本句】，仅重算该句并热替换音频。
  - 全部打包下载：一键导出包含 `01_xxx.wav`、`02_xxx.wav` 及 `manifest.json`、`list.txt` 的规范化 ZIP 压缩包。
- **可移植设计**：底层核心逻辑收敛于 `omnivoice/sentence_studio`，零 UI 强依赖，可作为通用对照蓝图直接迁移至其他 TTS 引擎。

### 3. 角色调用生成 (Direct PT Inference)
- **输入**：
  - 角色选择：从已保存的角色下拉列表中直接选取，或拖入外部 `.pt` 文件。
  - 目标文本：输入待合成内容（支持多段长文本，系统自动执行 12s~15s 智能分片与交叉渐变无缝拼接）。
  - 抑扬顿挫与起伏控制。
- **输出**：秒级直调底层扩散去噪，输出全景自适应波形与 24kHz 高保真语音。

### 4. 声音设计 (Voice Design)
- **输入**：性别、年龄段、基础音调、外语口音、中文方言等多维标签组合与目标文本。
- **输出**：生成专属定制属性音色。

## 核心设计与创新特性

### 1. 自然抑扬顿挫与情绪起伏机制
- **告别全局破坏性 Instruct 标签**：
  - 避免在开头粗暴施加全局情绪标签而导致角色原本特有的声线音色失真。保持 `instruct=None`，保护原声纯正度。
- **激活自然人声起伏微扰动 (`class_temperature = 0.35`)**：
  - 将底层离散 Gumbel 采样温度从 `0.0`（纯贪心 argmax）提升为 `0.35`，在 Top 候选空间引入微弱随机性，恢复人类日常说话时的自然升降调、轻重音与呼吸节奏，彻底打破扁平机械音。
- **显式【🎭 抑扬顿挫起伏度】控制滑块**：
  - 范围 0.0~0.8，配套 4 个一键预设：
    - `平缓克制 (0.1)`：适合严肃播报、官方通知。
    - `自然说话 (0.35 - 默认)`：真实人类聊天起伏。
    - `生动起伏 (0.5)`：讲故事、富有表现力的朗读。
    - `高昂激动 (0.7)`：高动态范围的兴奋起伏。
- **极简文本交互与文稿纯净度保障**：
  - 移除了早期版本在文本框下方硬编码的大块“韵律控制点”按键面板，避免过度侵占输入视野与造成视觉割裂。
  - 用户文稿保持干净整洁；如需局部细微情绪调节，可直接在文本中自然使用 `~`（延音）、`。`（呼吸沉淀）、`…`（沉思停顿）、`！`（情绪升调）或非语言标签（如 `[sigh]`），底层扩散模型自动识别并渲染。

### 2. 语种直切极简化
- 为高频的“中文原声快速转英文输出”量身定制药丸按钮：
  - `[🌐 自动检测]`
  - `[🇨🇳 中文 (Chinese)]`
  - `[🇬🇧 英文 (English)]`
- 点击瞬间联动同步下方完整的 600+ 语言下拉列表，省去繁琐翻找。

### 3. 性能排查与加载卡顿治理
- **性能实测证据**：
  - `VoiceClonePrompt.load` 反序列化耗时仅 **1.26 ms**（0.001 秒），文件大小仅 13KB。
- **耗时真相**：
  - 实际耗时主要来自：① GPU 密集的 32 步 DiT 扩散去噪计算（约 3~5 秒）；② 二次训练追加新音频时的 Whisper ASR 与 HiggsAudio 神经标记提取。
- **优化与保护**：
  - 内存级缓存：引入 `_PROMPT_CACHE` 与 `_VOICE_INFO_CACHE`，选定过的角色驻留内存，重复生成 0ms 磁盘开销。
  - 帧长安全保护：引入 `MAX_PROMPT_FRAMES = 250`（约 20 秒声学特征截断），阻断多段追加训练导致的注意力二次方复杂度膨胀。

### 4. 界面现代化美化
- 采用深色玻璃拟态设计（Deep Obsidian 墨玉底色、半透明磨砂玻璃面板）。
- 药丸分段式主选项卡切换导航与高光操作按钮。
- 专属角色声纹卡片：实时展示声纹帧数、预估参考时长、RMS 响度及参考文本摘要。

### 5. 长音频全景波形自适应与防遮挡时间栏
- **自适应响应式波形 (`minPxPerSec: 0`)**：修复 Gradio 默认对每秒音频分配 20 像素引发的长音频横向超宽溢出与右半段截断。无论音频 5 秒还是数分钟，波形均按卡片视口宽度 100% 自适应缩放，全景波峰波谷一览无余。
- **Shadow DOM 穿透暗色纤细滚动条**：在客户端注入 `Element.prototype.attachShadow` 拦截器，强制将 WaveSurfer 内部滚动条替换为 5px 纤细、半透明紫蓝微光滑块与暗黑底轨（`rgba(99, 102, 241, 0.45)`），彻底消除 Windows Chromium 默认原生亮白大粗条。
- **零遮挡防压字布局**：重构时间指示栏与波形下边距（增加 `margin-top: 8px` 与 `z-index: 5` 隔离层），使当前时间与总时长刻度永远清晰可见，避免滚动条压字。
