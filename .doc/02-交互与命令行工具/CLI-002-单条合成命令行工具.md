# CLI-002: 单条合成命令行工具 (`omnivoice-infer`)

## 用途与可观察行为
面向脚本调用与独立音频生成的 CLI 工具。通过参数化方式暴露模型的全部推理能力，支持直接输出 `.wav` 文件，适合快速验证、批处理脚本嵌套与流水线集成。

## 触发方式与示例
```bash
# 1. 声音克隆 (Voice Cloning)
omnivoice-infer \
    --model k2-fsa/OmniVoice \
    --text "欢迎使用全能多语言语音合成系统。" \
    --ref_audio sample.wav \
    --ref_text "这是参考音频的原话。" \
    --output result_clone.wav

# 2. 音色设计 (Voice Design)
omnivoice-infer \
    --model k2-fsa/OmniVoice \
    --text "今天的天气真不错，适合出去郊游。" \
    --instruct "female, low pitch, 四川话" \
    --output result_design.wav

# 3. 自动音色 (Auto Voice)
omnivoice-infer \
    --model k2-fsa/OmniVoice \
    --text "无需指定任何音色条件，由模型自由合成。" \
    --output result_auto.wav
```

## 参数解析
- `--model`: 模型 Hugging Face 仓库 ID 或本地模型绝对路径。
- `--text`: 待合成的文本内容。
- `--ref_audio`: 参考音频路径。
- `--ref_text`: 参考音频文本（省略时自动加载 Whisper 识别）。
- `--instruct`: 音色设计自然语言属性指令。
- `--output`: 输出音频文件路径（默认保存在指定路径，格式为 WAV）。
- `--num_step`: 扩散去噪步数（默认 32）。
- `--guidance_scale`: CFG 引导系数（默认 2.0）。
- `--speed`: 语速调节倍率。
- `--device`: 显存设备指定（如 `cuda:0`, `cpu` 等）。
