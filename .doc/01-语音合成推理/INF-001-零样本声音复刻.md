# INF-001: 零样本声音复刻 (Zero-Shot Voice Cloning)

## 用途与可观察行为
允许用户仅提供一段 3~10 秒的参考音频（Reference Audio），即可精准提取并复刻目标说话人的音色、音调基准与声学环境特征，并合成具有该音色的目标文本语音。支持显式提供参考音频转写文本，亦支持由内置 Whisper 自动识别转写；支持将声纹特征提炼为轻量 `VoiceClonePrompt` 对象并持久化为 `.pt` 文件供跨会话快速复用。

## 触发方式
- Python API：
  ```python
  audio = model.generate(
      text="合成目标文本",
      ref_audio="path/to/ref.wav",
      ref_text="参考音频文本内容"  # 可选，省略时自动调用 Whisper ASR
  )
  ```
- 声纹保存与复用：
  ```python
  prompt = model.create_voice_clone_prompt(ref_audio="ref.wav", ref_text="...")
  prompt.save("voices/my_voice.pt")
  # 复用：
  prompt = VoiceClonePrompt.load("voices/my_voice.pt")
  audio = model.generate(text="新文本", voice_clone_prompt=prompt)
  ```
- 命令行：`omnivoice-infer --ref_audio ref.wav --text "..." --output out.wav`

## 输入与输出
- **输入**：
  - `ref_audio`: WAV/MP3 等音频文件路径或内存音频元组
  - `ref_text`: 对应参考文本（字符串，可选）
  - `voice_clone_prompt`: `VoiceClonePrompt` 实例（替代 `ref_audio`）
  - `text`: 待合成文本
- **输出**：
  - 单声道、24kHz 的浮点 NumPy 数组或保存的音频文件

## 主流程
1. 若传入 `ref_audio` 且未提供 `ref_text`，调用模型内置的 Whisper 识别管道（`_asr_pipe`）提取文字。
2. 调用音频特征提取器与 `HiggsAudioV2TokenizerModel` 提取参考音频的多码本离散声学 Token，并计算参考音频的 RMS 响度。
3. 将参考声学 Token 与文本 Token 共同作为扩散语言模型的 Conditioning 上下文。
4. 扩散去噪头在条件约束下生成目标序列声学 Token，最后由 HiggsAudioV2 解码重构为波形。

## 参考音频标准与选材误区（并非越长越好）
- **黄金时长区间**：**5 ~ 15 秒**（1~2 句连贯自然的话即可，上限不超过 20 秒）。
- **为什么参考音频不是越长越好？**
  1. **显存与推理延迟**：声学 Token 随音频线性膨胀，长音频大量占用自回归注意力上下文窗口，导致首字延迟与显存占用成倍增加。
  2. **注意力漂移与幻听**：Prompt 序列过长容易导致模型注意力失焦，引发多余叹词、漏字、偶发性奇怪发音或跨语种混乱。
  3. **底噪与缺陷被强化学习**：长音频极易混入换气吞音、喷麦、环境回响或语调忽快忽慢；模型会将这些缺陷全盘当作说话人的“本质音色”加以模仿。
  4. **声文对齐与 ASR 窗口**：Whisper 单窗口上限 30 秒（3000 mel 帧），超长音频易出现切片边缘对齐失准。
- **选材准则**：**音质纯净度（无 BGM/无混响的纯干声）与代表性远重于音频时长**。
