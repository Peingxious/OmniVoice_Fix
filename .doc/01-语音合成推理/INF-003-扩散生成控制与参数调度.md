# INF-003: 扩散生成控制与参数调度

## 用途与可观察行为
精细化控制 Diffusion 语言模型的采样迭代、引导强度、时长估计、播放语速以及自然人声抑扬顿挫起伏。用户既可追求极致合成质量（32步以上去噪），也可追求极致推理速度（16步甚至更少），并能精确指定输出音频的固定时长或根据语种特性自适应预测。

---

## 关键参数体系 (`OmniVoiceGenerationConfig`)
| 参数名 | 默认值 | 作用说明 |
| :--- | :--- | :--- |
| `num_step` | 32 | 扩散采样迭代步数。设置为 16 可提速约 2 倍，且音质保持良好。 |
| `guidance_scale` | 2.0 | Classifier-Free Guidance (CFG) 引导系数，平衡内容忠实度与多样性。 |
| `class_temperature` | 0.35 | **抑扬顿挫起伏度 (自然起伏区间)**。控制离散 Gumbel 采样温度。为 0.0 时退化为贪心 argmax，声音扁平机械；设为 0.35 时恢复人类说话自然的升降调、轻重音与呼吸节奏。 |
| `t_shift` | 0.1 | 扩散时间步迁移调度超参数，用于优化去噪信噪比分布。 |
| `speed` | 1.0 | 语速调节倍率（>1.0 加速，<1.0 减速）。 |
| `duration` | `None` | 固定输出音频时长（秒）。当显式指定时，`speed` 参数自动忽略。 |
| `denoise` | `True` | 是否在生成后对音频执行背景降噪。 |
| `layer_penalty_factor` | 5.0 | 多码本分层惩罚因子，控制 RVQ 深层码本的生成稳定性。 |

## 抑扬顿挫起伏度与采样机制 (`class_temperature`)
在 Diffusion 语言模型的逆向去噪生成过程中，码本采样依赖概率分布预测：
1. **死板扁平原因 (`class_temperature = 0.0`)**：
   - 纯粹选择 logits 最大的声学 Token（argmax）。每个音素的音调都落在统计众数上，导致合成音频语调毫无波动，产生机械扁平感。
2. **自然拟人起伏 (`class_temperature = 0.35`)**：
   - 适当引入平滑的温度扰动，使模型有概率在相似候选音调中自然游走，精准还原人类朗读时的抑扬顿挫、重音转移与微弱语气起伏。
3. **区间建议**：
   - `0.1`：平缓克制，适合新闻资讯。
   - `0.35`（推荐默认）：自然说话，最接近真人交谈。
   - `0.5`：生动起伏，适合故事叙述与儿童读物。
   - `0.7`：高昂激动，适合强烈舞台情感。

## 时长估计机制 (`RuleDurationEstimator`)
若用户既未指定 `duration` 也未强行固定长度，模型通过 [omnivoice/utils/duration.py](file:///d:/BaiduNetdiskWorkspace/OmniVoice/omnivoice/utils/duration.py) 中的 `RuleDurationEstimator` 进行时长推断：
- 结合各语言音节/字符比率（如中英日韩字符发音特征基准时长）。
- 结合标点符号停顿权重（逗号、句号、感叹号、省略号赋予不同停顿秒数）。
- 结合语速因子动态计算生成目标帧数（Token 长度）。
