# 01-语音合成推理

## 边界与职责
本功能块覆盖 OmniVoice 的核心语音合成推理管线，涵盖从文本输入到声学生成、参数调度、非言语控制与音频重构全链路。

- **代码前缀**：`INF`
- **主要受众**：语音算法工程师、应用系统开发者与推理服务维护者

## 功能文件索引
- [INF-001-零样本声音复刻.md](INF-001-零样本声音复刻.md)：基于短音频的声音克隆、Prompt 提取与持久化跨会话复用。
- [INF-002-自然语言音色设计.md](INF-002-自然语言音色设计.md)：通过性别、年龄、音调、口音和方言属性指令定制专属音色。
- [INF-003-扩散生成控制与参数调度.md](INF-003-扩散生成控制与参数调度.md)：去噪步数、CFG scale、时长预测估计器与语速缩放控制。
- [INF-004-文本规整与发音非言语控制.md](INF-004-文本规整与发音非言语控制.md)：文本数字日期规整（WeTextProcessing/num2words）、拼音声调与副语言符号注入。
- [INF-005-音频长文本分块与拼接.md](INF-005-音频长文本分块与拼接.md)：标点智能切分、超长文本分块生成、淡入淡出与重叠交叉渐变拼接。
