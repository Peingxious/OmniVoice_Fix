# INF-002: 自然语言音色设计 (Voice Design)

## 用途与可观察行为
无需任何参考音频，用户仅需提供一组结构化或半自由的自然语言属性标签（Instruct），模型即可根据属性描述直接雕刻并生成全新虚拟声线。支持自由组合性别、年龄层、基频高低、发音风格、英语口音及中国各地方言。

## 触发方式
- Python API：
  ```python
  audio = model.generate(
      text="你好，这是通过属性描述定制的音色。",
      instruct="female, low pitch, 四川话"
  )
  ```
- 命令行：`omnivoice-infer --instruct "female, low pitch, british accent" --text "..." --output out.wav`
- WebUI：在 Gradio 界面中选择“音色设计”选项卡并下拉点选相应标签组合。

## 支持的属性维度
1. **性别 (Gender)**：`female` (女性), `male` (男性)
2. **年龄 (Age)**：`child` (儿童), `teenager` (少年), `young adult` (青年), `middle aged` (中年), `elderly` (老年)
3. **音调 (Pitch)**：`very low pitch`, `low pitch`, `moderate pitch`, `high pitch`, `very high pitch`
4. **说话风格 (Style)**：`whisper` (耳语/轻声细语)
5. **英语口音 (English Accent)**：`american accent`, `british accent`, `australian accent`, `indian accent` 等
6. **汉语方言 (Chinese Dialect)**：`四川话`, `陕西话`, `粤语`, `东北话`, `河南话`, `山东话`, `闽南话`, `上海话`, `天津话` 等

## 主流程
1. [omnivoice/utils/voice_design.py](file:///d:/BaiduNetdiskWorkspace/OmniVoice/omnivoice/utils/voice_design.py) 中的 `parse_instruct` 对输入属性字符串进行清洗、校验与互斥性检查（例如不可同时设置 `female` 与 `male`）。
2. 将解析并规范化后的属性 Token 拼接入文本特征序列前部作为 Condition 提示。
3. 扩散语言模型在无音频 Prompt 条件下，根据属性提示引导生成目标声纹 Token。
