# 06-评测与基准测试

## 边界与职责
本功能块覆盖语音合成系统全维度的客观度量指标，从内容准确性（字/词错误率 WER/CER）、音色还原度（Speaker Similarity）到听感自然度（UTMOS 评分），为模型选型、训练迭代与消融实验提供统一客观的标准。

- **代码前缀**：`EVL`
- **主要受众**：语音评测工程师、算法研究员

## 功能文件索引
- [EVL-001-词错误率与多模型ASR基准评测.md](EVL-001-词错误率与多模型ASR基准评测.md)：基于 FunASR SenseVoice、Whisper、HuBERT、FLEURS 的多模型识别比对与文本规整评测。
- [EVL-002-说话人相似度评测.md](EVL-002-说话人相似度评测.md)：利用 ECAPA-TDNN 与 WavLM 声纹提取器计算余弦相似度（SIM）。
- [EVL-003-语音自然度MOS评分预测.md](EVL-003-语音自然度MOS评分预测.md)：基于神经网络 UTMOS 自动化预测合成语音的自然度主观分。
