# EVL-002: 说话人相似度评测 (Speaker Similarity, SIM)

## 用途与可观察行为
评估零样本声音克隆（Voice Cloning）生成的音频与真实参考音频之间音色逼真度与说话人特征重合度。通过提取两段音频的声纹嵌入向量（Speaker Embeddings），计算余弦相似度（Cosine Similarity），取值范围在 0.0 ~ 1.0 之间，数值越高代表音色还原度越完美。

## 触发方式与 API
```python
from omnivoice.eval.speaker_similarity.sim import compute_similarity

sim_score = compute_similarity(
    ref_audio_path="ref.wav",
    syn_audio_path="syn.wav",
    model_type="ecapa_tdnn" # 或 "wavlm"
)
print(f"说话人相似度: {sim_score:.4f}")
```

## 底层声纹模型支撑
1. **ECAPA-TDNN**：高效基于 TDNN 的声纹识别模型，广泛用于说话人验证。
2. **WavLM-Large**：基于自监督语音表征的深度声纹提取器，在复杂声学环境与跨语种声纹比对上具备极高判别力。
